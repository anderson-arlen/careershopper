  changing the artwork. Source:
  https://static.licdn.com/aero-v1/sc/h/al2o9zrvru7aqj8e1x2rzsrca

  in Indeed Blue (#003A9B). Source:
  https://cdn.jsdelivr.net/npm/simple-icons@13/icons/indeed.svg
